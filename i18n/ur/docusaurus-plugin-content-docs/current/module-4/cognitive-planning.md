# کوگنیٹو ٹاسک پلاننگ

ہیومنوڈ ٹاسک execution کے لیے پیچیدہ فیصلہ سازی اور اعلیٰ سطحی حکمت عملی۔

## تصور کی وضاحت
کوگنیٹیو پلاننگ روبوٹ کو اعلیٰ سطحی اہداف کو سمجھنے، ان کو ذیلی کاموں میں تقسیم کرنے، اور ترتیب میں انجام دینے کے قابل بناتی ہے۔

## آرکیٹیکچر ڈایاگرام
```text
[ہدف] -> [منصوبہ بند] -> [ٹاسک ڈیکومپوزیشن] -> [ترتیب شدہ کام] -> [Execution]
              ^                              |
              +------------------------------+
                    (Resource/Constraint Checking)
```

## اہم اجزا
- **Hierarchical Task Networks (HTN)**: کاموں کی ہیرررکی کی نمائندگی
- **State Machines**: روبوٹ کی حالت کی ٹریکنگ
- **Constraint Solvers**: وسائل اور پابندیوں کا انتظام

## ٹولنگ اسٹیک
- ROS 2 Behavior Trees
- SMACH
- GROOT
- PyTree

## عملی سیکھنے کے اہداف
1. Behavior Trees کی تعمیر کریں
2. پیچیدہ کاموں کو ذیلی کاموں میں تقسیم کریں
3. وسائل کی پابندیوں کو سنبھالیں
4. فیڈبک کے ساتھ منصوبے کو ایڈجسٹ کریں
