# روبوٹکس میں LLMs

Large Language Models (LLMs) اور ان کے روبوٹک ہارڈ ویئر کے ساتھ انٹرفیس کا تعارف۔

## تصور کی وضاحت
LLMs جیسے GPT-4 روبوٹکس میں ایک انقلابی تبدیلی لا رہے ہیں۔ یہ ماڈلز قدرتی زبان کو سمجھنے، منصوبہ بندی کرنے، اور پیچیدہ کاموں کو مرحلہ وار ہدایات میں تبدیل کرنے کے قابل ہیں۔

## آرکیٹیکچر ڈایاگرام
```text
[انسانی ہدایت] -> [LLM (GPT-4/Claude)] -> [منصوبہ بندی] -> [ROS 2 Actions] -> [روبوٹ]
        ^                                       |
        +---------------------------------------+
              (فیڈبک اور درستی)
```

## اہم اطلاقات
- **قدرتی زبان کمانڈز**: "میز پر کتاب رکھو" جیسی ہدایات کو سمجھنا
- **منصوبہ بندی**: پیچیدہ کاموں کو آسان مرحلوں میں تقسیم کرنا
- **فیڈبک لوپ**: غلطیوں سے سیکھنا اور اپنی حکمت عملی ایڈجسٹ کرنا

## ٹولنگ اسٹیک
- OpenAI GPT-4 / Anthropic Claude
- LangChain / LlamaIndex
- ROS 2 Actions
- Vector Databases (RAG کے لیے)

## عملی سیکھنے کے اہداف
1. LLMs کو ROS 2 سسٹم کے ساتھ مربوط کریں
2. 自然言語 ہدایات کو روبوٹ کمانڈز میں تبدیل کریں
3. LLM-based منصوبہ بندی کو لاگو کریں
