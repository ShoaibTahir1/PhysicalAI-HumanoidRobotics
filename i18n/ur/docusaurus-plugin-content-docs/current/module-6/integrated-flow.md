# انٹیگریٹڈ فلو: ویس → پلان → نیویگیٹ → فیرسیپ → ایکٹ

"انٹیگریٹڈ فلو" وہ واقعوں کی ترتیب ہے جو ایک روبوٹ کو انسان کی تجریدی آواز کے حکم کو متحرک جسمانی حرکات کے ایک سلسلے میں ترجمہ کرنے کے قابل بناتی ہے۔

## سیکھنے کے اہداف
- ایک کمانڈ کے ذریعہ روبوٹ کے سافٹ ویئر سٹیک کے لائف سائیکل کو ٹریس کریں
- روبوٹک فیصلہ سازی کے لیے وژن اور زبان کے سنگم کو سمجھیں
- روبوٹ کے کاموں کو منظم کرنے کے لیے state-machine یا behavior-tree لاگو کریں

## تصور کی وضاحت
روبوٹک آٹونومی صرف ایک ماڈل نہیں؛ یہ ایک **پائپ لائن** ہے۔ جب آپ روبوٹ سے کہتے ھیں "مجھے بوتل لاؤ"، کئی الگ AI سسٹمز کو تعاون کرنا ہوتا ہے۔

### پائپ لائن مرحلے
1. **ویس:** آڈیو کو ASR کا استعمال کرتے ہوئے ٹیکسٹ میں تبدیل کیا جاتا ہے
2. **پلان:** LLM نے ارادہ اور پیرامیٹر نکالے
3. **نیویگیٹ:** روبوٹ کچن تک جانے کے لیے اپنے اندرونی نقشے کا استعمال کرتا ہے
4. **فیرسیپ:** وہاں پہنچ کر، VLM کاؤنٹر پر بوتل کی نشاندہی کرتا ہے
5. **ایکٹ:** موشن پالیسی grasp اور return movement انجام دیتی ہے

## سسٹم آرکیٹیکچر
فلو **Behavior Tree (BT)** کا استعمال کرتے ہوئے منظم ہوتا ہے:
- **Root Node:** مین ٹاسک کنٹرولر
- **Sequence Node:** کمانڈ سننا → ٹیکسٹ کا تجزیہ → ارادے کی تصدیق
- **Fallback Node:** اگر物体 نہیں ملی → 360 درجے گھومنا
- **Action Node:** ٹانگوں/کالوں کو velocity کمانڈز بھیجنا
