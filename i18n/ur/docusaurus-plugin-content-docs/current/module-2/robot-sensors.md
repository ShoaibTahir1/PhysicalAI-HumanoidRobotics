# روبوٹ سینسرز: LiDAR، ڈیپتھ کیمرے، اور IMUs

## تصور کی وضاحت
سینسرز ہیومنوڈ روبوٹ کی آنکھیں اور کان ہیں۔ وہ فیسپشن اور لوکلائزیشن کے لیے درکار خام ڈیٹا فراہم کرتے ہیں۔
- **LiDAR**: فاصلہ ماپنے کے لیے روشنی کی پلسس استعمال کرتا ہے، 360-ڈگری میپ بناتا ہے
- **Depth Cameras (RGB-D)**: ہر پکسل کے لیے رنگ اور فاصلے کا ڈیٹا فراہم کرتا ہے،物体 پہچان کے لیے ضروری
- **IMU**: تیزی اور زاویائی رفتار ماپتا ہے، ہیومنوڈز میں توازن برقرار رکھنے کے لیے اہم

## آرکیٹیکچر ڈایاگرام
```text
[ماحول] -> [سینسرز] -> [خام ڈیٹا (LaserScan/Image)] -> [پروسیسنگ Node]
      |                                                        |
      +------------------< [فیڈبک لوپ (IMU)] <------------+
```

## ٹولنگ اسٹیک
- OpenCV (تصویر پروسیسنگ)
- PCL (Point Cloud Library)
- ROS 2 Sensor Messages (`sensor_msgs`)
- Rviz2 (ویژولائزیشن)

## عملی سیکھنے کے اہداف
1. Time-of-Flight (ToF) اور Structured Light کیمرے کے درمیان فرق کریں
2. شور کم کرنے کے لیے LiDAR point clouds فلٹر کریں
3. روبوٹ کی سمت کے لیے IMU ڈیٹا کی تفسیر کریں (roll, pitch, yaw)
4. درست فیسپشن کے لیے متعدد سینسر سٹریمز کو سنکرونائز کریں
