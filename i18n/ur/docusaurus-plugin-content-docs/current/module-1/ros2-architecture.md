# ROS 2 آرکیٹیکچر

Robot Operating System (ROS 2) صنعت کا معیاری مڈل ویئر ہے جو روبوٹ سافٹ ویئر بنانے کے لیے استعمال ہوتا ہے۔ یہ روبوٹ کے مختلف حصوں ("اعصابی نظام") کو ایک دوسرے سے بات کرنے کے لیے ایک منظم طریقہ فراہم کرتا ہے۔

## تصور: تقسیم شدہ پروسیسنگ

ROS 2 ایک پیئر-ٹو-پیئر آرکیٹیکچر استعمال کرتا ہے جہاں سافٹ ویئر کو چھوٹے، دوبارہ قابل استعمال پروگراموں میں تقسیم کیا جاتا ہے جنھیں **Nodes** کہا جاتا ہے۔ یہ نودز قائم پیٹرن کا استعمال کرتے ہوئے مواصلات کرتے ہیں۔

## آرکیٹیکچر ڈایاگرام
```text
[Node A: کیمرا] --- (Topic: /image_raw) ---> [Node B: Object Detection]
[Node C: دماغ]  <-- (Service Call) --------> [Node D: Map Server]
[Node C: دماغ]  === (Action: Navigate) ====> [Node E: Base Controller]
```
*وضاحت: Topics (ڈیٹا سٹریمنگ)، Services (درخواست/جواب)، اور Actions (فیڈبک اور منسوخی کے ساتھ لمبے اہداف) کے ذریعے نودز کی طرح سے منسلک۔*

## اہم اجزا
- **Nodes**: انفرادی پروسیسز جو کمپیوٹیشن کرتے ہیں
- **Topics**: ڈیٹا سٹریمنگ کے لیے غیر متزامن "بس" (Publisher/Subscriber)
- **Services**: ہم وقت درخواست/جواب مواصلات
- **Actions**: فیڈبک اور منسوخی کے ساتھ اہداف کے لیے اعلیٰ سطحی مواصلات
- **Parameters**: نودز کی ترتیب کے لیے عالمی متغیرات

## ٹولنگ اسٹیک
- **RCL (ROS Client Libraries)**: Python کے لیے rclpy، C++ کے لیے rclcpp
- **Rviz2**: ویجولائزیشن ٹول
- **Rqt**: گرافیکل یوزر انٹرفیس ٹولز
- **DDS (Data Distribution Service)**: بنیادی ٹرانسپورٹ لیئر

## عملی سیکھنے کے اہداف
1. روبوٹکس میں مڈل ویئر کے کردار کی وضاحت کریں
2. Topics، Services، اور Actions کے درمیان فرق کریں
3. سمجھیں کہ تقسیم شدہ نودز سسٹم کی وشوسنییتا میں کیسے حصہ ڈالتے ہیں
