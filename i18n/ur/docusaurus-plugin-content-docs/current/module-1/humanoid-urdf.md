# ہیومنوڈ URDF

Unified Robot Description Format (URDF) ایک XML پر مبنی زبان ہے جو ہیومنوڈ روبوٹ کی بصری، جسمانی، اور کائینیٹک خاصیات کو بیان کرنے کے لیے استعمال ہوتی ہے۔

## تصور: کائینیٹک چینز

ایک ہیومنوڈ روبوٹ کو **Links** (اعضا/حصے) اور **Joints** (پیوٹس/موٹرس) کے مجموعے کے طور پر بیان کیا جاتا ہے۔ URDF کمپیوٹر کو بتاتا ہے کہ ٹانگوں، پیروں، اور سر کی پوزیشن ٹورسو کے نسبت سے کہاں ہے۔

## آرکیٹیکچر ڈایاگرام
```text
[Torso Link]
    |
    +-- [Shoulder Joint] -- [Upper Arm Link]
    |
    +-- [Neck Joint] -- [Head Link]
    |
    +-- [Hip Joint] -- [Thigh Link]
```
*وضاحت: روبوٹ کے ڈھانچے کی نمائندگی کرنے والی ایک ٹری ساخت (ہیرarchy)۔*

## اہم عناصر
- **Links**: بصری (میش)، تصادم (طبیعیات)، اور惯性 (ماس/کشش ثقل) خاصیات
- **Joints**: قسم (revolute, fixed, prismatic)، حدیں (زاویے)، اور پیرنٹ/چائلڈ تعلقات
- **Transmission**: مکینیکل ریڈکشن اور موٹر تفصیلات

## ٹولنگ اسٹیک
- **XML**: بنیادی زبان
- **Xacro**: XML Macros برائے پیچیدہ ہیومنوڈ فائلوں کو آسان بنانے کے لیے
- **MeshLab / Blender**: 3D بصری اور تصادم میشز بنانے کے لیے
- **Rviz2**: روبوٹ ماڈل کو دیکھنے کے لیے

## عملی سیکھنے کے اہداف
1. روبوٹ ماڈل کی ٹری پر مبنی ساخت کو سمجھیں
2. بصری، تصادم، اور inertial خاصیات کے درمیان فرق کریں
3. سیکھیں کہ ہیومنوڈ joints کے لیے حرکت کی پابندیاں کیسے متعریف کریں
