# سینسرز اور ایکچوایٹرز ہارڈویئر گائیڈ

ایک ہیومنوڈ روبوٹ اپنے سینسرز (فیسپشن) اور ایکچوایٹرز (کاروائی) کے ذریعے ڈیجیٹل اور جسمانی دنیوں کو جوڑتا ہے۔ صحیح ہارڈویئر کا انتخاب اور انضمام روبوٹ کی استحکام اور ذہانت کے لیے اہم ہے۔

## سیکھنے کے اہداف
- ہیومنوڈ توازن اور فضائی جاگیری کے لیے درکار سینسرز کی اقسام کی نشاندہی کریں
- مختلف ایکچوایٹر ٹیکنالوجیز (Quasi-Direct Drive vs. Series Elastic) میں فرق کریں
- ہائی-فریکوئنسی فیڈبک لوپس کے لیے کمیونیکیشن پروٹوکولز کو سمجھیں

## تصور کی وضاحت
سینسرز فزیکل AI کے "دماغ" کو چلانے والا ڈیٹا فراہم کرتے ہیں، جبکہ ایکچوایٹرز نیورل نیٹ ورک کی "ارادے" پر عمل درآمد کرتے ہیں۔ ایک ہیومنوڈ میں، گرنے سے روکنے اور ہموار ہیراپولیشن کو یقینی بنانے کے لیے ان اجزا کو ہائی فریکوئنسی (500Hz تا 1kHz) پر سنکرونائز کرنا ضروری ہے۔

### ضروری اجزا
- **فیسپشن سینسرز:** Stereo Depth Cameras، LiDAR، IMUs
- **Proprioception سینسرز:** Joint position کے لیے encoders، contact detection کے torque sensors
- **ایکچوایٹرز:** High-torque density motors (BLDC)

## سسٹم آرکیٹیکچر
1. **ہائی-لیول فیسپشن (نام ریل-ٹائم):** کیمرے اور LiDAR
2. **مڈ-لیول پلاننگ (سافٹ ریل-ٹائم):** ROS 2 navigation nodes
3. **لو-لیول کنٹرول (ہارڈ ریل-ٹائم):** CAN FD یا EtherCAT
4. **جسمانی انٹرفیس:** کاربن فائبر یا Aluminum ڈھانچہ

## ٹولز اور ٹیکنالوجیز
- CAN FD / EtherCAT
- Dynamixel / Unitree Motors
- Intel RealSense / OAK-D
- VectorNav / Xsens
