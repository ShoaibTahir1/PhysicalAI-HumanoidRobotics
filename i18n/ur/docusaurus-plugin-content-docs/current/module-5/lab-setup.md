# لیب سیٹ اپ: On-Prem بمقابلہ کلاؤڈ

فزیکل AI کے لیے لیب بنانا مقامی ہارڈویئر کی صلاحیتوں اور کلاؤڈ پر مبنی اسکیل ایبلٹی کے درمیان توازن کی طلب کرتا ہے۔ یہ باب آپ کو ایک ایسا ماحول بنانے میں رہنمائی کرتا ہے جو Sim-to-Real خطرات کو کم کرے اور ترقی دہندگان کی کارکردگی کو زیادہ سے زیادہ کرے۔

## سیکھنے کے اہداف
- روبوٹکس کے لیے On-Premise بمقابلہ کلاؤڈ GPUs کے فوائد اور لاگت کا موازنہ کریں
- ہیومنوڈ ٹیسٹنگ کے لیے موزو جگہ ڈیزائن کریں (سیفٹی اور ایکویپمنٹ)
- ماڈل تربیت اور سمولیشن کے لیے ہائبرڈ ورک فلو لاگو کریں

## تصور کی وضاحت
روبوٹکس ترقی کو منفرد انفراسٹرکچر کی ضرورت ہوتی ہے۔ چونکہ جسمانی روبوٹس مہنگے اور خطرناک ہو سکتے ہیں، ایک "لیب" ڈیسک سے زیادہ ہے؛ یہ ایک کنٹرولڈ ماحول ہے۔

### Sim-to-Real Gap
لیب سیٹ اپ کا ایک بڑا مقصد **Sim-to-Real Gap** کو کم کرنا ہے—سمولیٹڈ طبیعیات اور حقیقی دنیا کے رویے کے درمیان فرق۔

## سسٹم آرکیٹیکچر
1. **کلاؤڈ لیئر:** GPU clusters (NVIDIA A100s) برائے Hyperparameter Optimization
2. **On-Prem لیئر:** مقامی RTX Workstations برائے روزانہ کوڈنگ اور ڈیبگنگ
3. **فیزیکل ٹیسٹنگ لیئر:** Safety Gantry، Motion Capture، Computing Bench

## ٹولز اور ٹیکنالوجیز
- NVIDIA Omniverse Cloud
- Docker-Compose
- Terraform/Ansible
- VS Code Remote - Tunnels
