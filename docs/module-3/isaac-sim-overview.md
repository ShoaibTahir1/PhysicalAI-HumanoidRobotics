# Isaac Sim Overview

## Concept Explanation
NVIDIA Isaac Sim is a reference application built on NVIDIA Omniverse that provides a robotics simulation and synthetic data generation tool. It enables developers to design, simulate, and test AI-based robots in photorealistic environments.

## Architecture Diagram Description
The Isaac Sim architecture consists of the following layers:
- **Omniverse Nucleus**: The collaborative platform for storing and sharing assets.
- **USD (Universal Scene Description)**: The core data format for scene description.
- **Physics Engine (PhysX)**: Provides high-fidelity physics simulations.
- **OmniGraph**: A visual scripting interface for robot behavior and sensor logic.
- **Isaac SDK/ROS 2 Bridges**: Connectivity for robot control and messaging.

## Tooling Stack
- NVIDIA Omniverse
- USD (Universal Scene Description)
- Python API
- ROS 2 Bridge
- URDF/MJCF Importers

## Practical Learning Goals
1. Navigate the Isaac Sim environment.
2. Import URDF models into Isaac Sim.
3. Understand the USD workflow.
4. Set up physics properties for humanoid robots.
