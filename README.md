# Physical AI & Humanoid Robotics Educational Book

This is an educational book about Physical AI and Humanoid Robotics, explaining how digital brains (AI models) control physical bodies (robot hardware) in a simple, step-by-step way.

## About this Book

This book is designed to be a calm, beginner-friendly guide that helps students understand how Artificial Intelligence works with physical systems, especially humanoid robots. The content is written in simple English with short paragraphs, real-life examples, and a friendly teaching tone.

## Chapters

The book covers the following topics:

1. Introduction to Physical AI
2. What Is Embodied Intelligence?
3. From Software to Physical Motion
4. Sensors: How Robots Sense the World
5. Actuators & Motors: How Robots Move
6. Humanoid Robot Structure
7. Balance, Walking & Posture
8. Understanding URDF (Unified Robot Description Format) for Humanoids
9. AI Models That Control Robotic Bodies
10. Simulation vs Real-World Robotics
11. Safety & Ethical Considerations
12. Future of Humanoid Robotics
13. Glossary
14. Final Summary

## Getting Started

To run this book locally:

1. Make sure all required chapters are created in the `docs/` directory
2. Install dependencies: `npm install`
3. Start the development server: `npm start`
